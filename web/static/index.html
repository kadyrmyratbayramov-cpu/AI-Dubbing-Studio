AI Dubbing Studio

This is the runnable v1.0 application foundation for future dubbing workflows.

Available run modes

  • python main.py info — inspect runtime metadata
  • python main.py check — initialize the scaffold
  • python main.py serve-api — start the backend skeleton
  • python main.py serve-web — start the frontend preview

Current scope

Backend and frontend entry points are ready for future Whisper, TTS, translation, diarization, and lip-sync integration.
